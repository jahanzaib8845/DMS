# 🚗 Driver Management System (DMS)

A full‑stack web application for registering and managing driver records. The system provides a clean React‑based user interface and a RESTful API backend built with Express.js and MongoDB.

## ✨ Features

- **Driver Registration** – Submit driver details (name, CNIC, city, car type) through a user‑friendly form.
- **Data Persistence** – All records are stored securely in a MongoDB database.
- **RESTful API** – Clean, well‑structured backend endpoints for driver management.
- **Responsive Frontend** – React‑powered UI that works on desktop and mobile devices.
- **Real‑time Validation** – Frontend and backend validation ensure data integrity.

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v14 or later)
- **npm** or **yarn**
- **MongoDB** (local instance or cloud service like MongoDB Atlas)
